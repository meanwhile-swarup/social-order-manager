# Facebook Messenger Bot & Business Admin Panel

A collaborative web application designed for businesses to automate customer inquiries on Facebook Messenger and manage incoming orders through a centralized admin dashboard.



## 1. System Architecture
1. Messenger Bot: Receives customer messages, executes response logic, and saves order entries.
2. Admin Panel: Displays real-time order lists, status updates, customer details, and sales analytics.
3. Database: Persists products, customer details, active conversation states, and order histories.
